# Omarchy plugins

Format: `manifest.json` with `schemaVersion: 1`, `kinds` and `entryPoints` (see `omarchy plugin add`). Install from a clone with `omarchy plugin add`, or from a single-plugin mirror URL. Empty for now.

The AirPods plugin for Omarchy already exists upstream: [omarchy-pods](https://github.com/thisisgm/omarchy-pods).
